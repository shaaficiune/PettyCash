# 🚀 Petty Cash App – Ubuntu Local Server Deployment (PM2 + Nginx)

Guide for deploying **Petty Cash Management System** on Ubuntu Server (`10.35.70.251`).

---

## 📋 Quick Setup Commands (Ubuntu Server: 10.35.70.251)

### Step 1: Install Required System Packages
```bash
sudo apt update && sudo apt upgrade -y

# 1. Install Node.js 20 LTS
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs git nginx postgresql postgresql-contrib

# 2. Install PM2 Globally
sudo npm install -g pm2
```

---

### Step 2: Configure PostgreSQL Database
```bash
sudo -u postgres psql
```
Inside PostgreSQL prompt (`psql`), run:
```sql
ALTER USER postgres PASSWORD 'Somtel@PL';
CREATE DATABASE petty_cash_db;
\q
```

---

### Step 3: Clone Project & Run 1-Click Deployment Script
```bash
# Target installation directory
sudo mkdir -p /var/www/petty-cash
sudo chown -R $USER:$USER /var/www/petty-cash

cd /var/www/petty-cash
git clone https://github.com/shaaficiune/PettyCash.git .

# Grant execute permissions & run deploy script
chmod +x deploy-ubuntu.sh
./deploy-ubuntu.sh
```

---

### Step 4: Configure Nginx Web Server Proxy
```bash
sudo cp nginx-ubuntu.conf /etc/nginx/sites-available/petty-cash
sudo ln -sf /etc/nginx/sites-available/petty-cash /etc/nginx/sites-enabled/default
sudo nginx -t
sudo systemctl reload nginx
```

---

### Step 5: Enable PM2 Auto-Start on System Boot
```bash
pm2 startup
# Run the command generated by pm2 startup (starts with 'sudo env PATH=...')
pm2 save
```

---

## 🛠 Useful Operational Commands

| Action | Command |
| :--- | :--- |
| **Check Backend Status** | `pm2 status` |
| **View Live Backend Logs** | `pm2 logs petty-cash-backend` |
| **Restart Backend** | `pm2 restart petty-cash-backend` |
| **Check Nginx Status** | `sudo systemctl status nginx` |
| **Reload Nginx** | `sudo systemctl reload nginx` |
